# SD2 硬件基线

## 先确定目标板

本指南的基线是主版 SD2，ESP8266 系列模组配 1.54 英寸、240×240、SPI ST7789 方屏。原厂资料列 ESP-12F、CH340C、Type-C 输入和 AMS1117-3.3 稳压。AI 工程注释列 ESP-12S，开发板配置也与其他工程不同。识别实物丝印、屏幕尺寸、串口芯片和 Flash 容量后再选配置。1.33 英寸 SD mini 有独立的 PCB、源码、外壳和镜像，应转查其配套资料。

| 信号 | ESP8266 | 板上标号 | 核对重点 |
|---|---|---|---|
| TFT SCLK / MOSI | GPIO14 / GPIO13 | D5 / D7 | 硬件 SPI 时钟和数据 |
| TFT CS | GPIO15 | D8 | 复位采样时保持低电平 |
| TFT DC | GPIO0 | D3 | 正常从 Flash 启动时高，进入串口下载时低 |
| TFT RESET | GPIO2 | D4 | 复位采样时保持高电平 |
| TFT 背光 | GPIO5 | D1 | 比对项目 PWM 范围和极性，再测两个亮度档 |
| DHT11 DATA | GPIO12 | D6 | 可选，按装配情况启用 |
| UART TX / RX | GPIO1 / GPIO3 | TX / RX | 应用串口 115200、8-N-1。接外置 USB-TTL 时共地，使用 3.3 V 逻辑，TX 接对端 RX |

Type-C 为成品板供电，ESP 模组侧使用稳定的 3.3 V。把外接屏或可选传感器接到启动脚时，先核对复位时的电平。原厂 V1.4 的 TFT 配置是 ST7789、RGB、27 MHz。BTC 和 Home Assistant 同为 27 MHz，TeslaMate 和 AI 工程使用 40 MHz；这是 **屏幕 SPI 时钟**。Flash 写入频率要从镜像的发行说明另行核对。AI 使用低有效背光并反转 PWM，另外三个工程直接写亮度。移植时保留选定工程的配置，颜色、旋转与亮度最后用实机确认。

诊断复位时可用 74880 波特率读取 ESP8266 ROM 启动信息，应用启动后切回 115200。GPIO2 用上拉，不要硬接 VCC，下载模式会把该脚切换为输出。[乐鑫 ESP8266 启动模式说明](https://docs.espressif.com/projects/esptool/en/latest/esp8266/advanced-topics/boot-mode-selection.html)
