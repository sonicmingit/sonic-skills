## 目录与持久化

必须按实际部署生成带中文说明的目录层级树。下列仅示意，交付时替换为真实名称、真实文件和必要层级；未使用的目录删去，省略的内部内容明确标记。

```text
./sonic-notes/                   # 本套应用的部署根目录；未指定服务器绝对位置时使用相对表示
├── README.md                    # 实际部署、日常操作和恢复说明
├── deploy.sh                    # 自建源码项目的一键更新与部署入口
├── docker-compose.yaml          # Compose 主入口；采用 CLI 时替换为 docker-run.sh
├── .env                         # 本实例实际环境参数，不提交仓库
├── .env.example                 # 无真实凭据的参数示例
├── app/                         # 程序源码、产物或构建上下文，按需保留
│   ├── source/                  # Git 仓库完整源码，保留上游结构
│   │   ├── .git/                # 源码版本记录，内部内容省略
│   │   ├── Dockerfile           # 项目提供或实际采用的镜像构建文件，按需保留
│   │   └── …                    # 项目源码，实际交付时补充相关层级
│   └── dist/                    # 按需：宿主机编译后的独立发布产物
├── config/                      # 宿主管理的配置及部署状态
│   ├── api/                     # API 实际配置，与源码默认模板分离
│   │   └── application.yaml     # 按需：本实例配置，更新保留定制值并检查新版配置变化
│   └── deploy-state/            # 最后成功部署的提交和镜像等状态，不放进源码目录
├── data/                        # 必须保留的持久业务数据
│   └── postgres/               # 数据库数据，内部生成文件不逐项展开
├── logs/                        # 应用文件日志；仅标准输出时省略
├── backups/                     # 本地一致性备份导出，独立副本另行记录
└── scripts/                     # 辅助运维脚本
    ├── backup-data.sh           # 本项目的数据备份入口
    └── restore-data.sh          # 本项目的恢复入口
```

对目录树之外的命名卷、共享路径、符号链接目标和独立备份位置另行说明。目录树不展示凭据值或隐私数据名称，结构变更后同步维护。

| 宿主相对路径或命名卷 | 容器目标路径 | 用途 | 读写属性 | 必须保留 |
|---|---|---|---|---|

## 首次部署

记录配置来源、必需目录、环境参数名称、凭据获取方式、UID/GID 与初始化步骤。不填写真实凭据。

说明仓库默认配置与 `./config/` 实际配置的对应关系、首次初始化方式、外部配置加载及覆盖优先级；更新时对照旧模板、新模板与实际配置，记录新增项和配置迁移，不覆盖实例定制值。记录模板基线、配置备份和生效验证方式。

源码部署时明确 Git 仓库与目标分支，默认源码位置为 `app/source/`。说明采用 Docker 内编译还是宿主机编译，并填写真实构建命令、构建上下文、Dockerfile、产物路径及产物入镜像或挂载方式。仅在需要时创建 `app/dist/`，运行配置及数据保留在源码工作区之外。

## 常用操作

填写本项目已核实的配置校验、启动、停止、状态、日志和重新创建方式。说明命令工作目录与项目名覆盖项，命令采用相对业务路径。

自建源码项目另说明 `deploy.sh` 的代码来源、跟踪分支、参数和判断更新的依据；提供人工调用与 `--non-interactive` 的 Agent 调用示例，说明无更新时的行为、失败恢复及成功部署状态存放位置。

已有开发阶段脚本时，记录仓库中的唯一来源路径，以及更新后复制到部署根目录、保留并调整实例配置、校验再执行根目录脚本的步骤。所有实例业务路径默认相对部署根目录；说明从其他工作目录调用时脚本如何定位，避免把仓库目录或调用者当前目录当成部署根目录。

## 更新、备份与恢复

记录版本变更位置、更新步骤、停机影响、数据迁移兼容性、一致性备份与保留方式、独立副本位置、恢复顺序和恢复验证。区分已验证的备份与尚未演练的恢复。

宿主产物挂载时说明暂存构建、版本切换及旧产物保留方式，不在运行目录中直接覆盖编译。记录验收超时、有限重试和失败退出约定；部署失败但回滚成功仍按本次部署失败报告。同步脚本所需依赖及 Compose 模板时，说明复制后的路径调整、实例值保留及环境变量传递方式。
