# 更新日志

## 2026-11-05

### 支持自然语言检测自建技能

- 新增“检测我创建的 Skill”“检测我创建的技能”等调用说法，并保留原有调用方式。
- 维护源目录中的自建旧技能即使尚无 Sonic- 前缀也纳入检查；其他目录按前缀或明确归属识别，排除归属不明的第三方技能。
- 明确“只检测，不同步”只报告差异。

### 区分英文目录与中文技能名称

- 技能目录改用 Sonic- 前缀加英文，技能本身的名称、显示名称及说明仍使用中文。
- 本规范目录由 `Sonic-技能创建规范` 改为 `Sonic-skill-rules`，同步调整仓库入口、全局规则路径与安装链接。

### 新增本机检查与更新日志规则

- 新增按需扫描维护源、Codex、通用代理、Claude Code 用户目录及当前项目技能目录的流程。
- 新增 sonic- 前缀匹配、链接去重、完整内容比较、冲突判断和可确认本地更新的 GitHub 同步流程。
- 要求每个自建技能每次实际更新均维护中文 `CHANGELOG.md`，并与技能内容一起提交。
- 扩展技能说明和调用提示，支持“检查本机 sonic- 技能，有更新就同步”。
