# 工作区与模型规则

## 固定目录与命名

```text
aipassport/
├── AGENTS.md
├── README.md                    # 包含 tree 树和索引
├── 01-docs/                     # 开发、模型、配置页和交付规范
├── 02-materials/                # 公共资料与来源
├── 03-sources/ai-passport/       # 完整上游基线
├── 04-projects/<project-name>/
│   ├── README.md
│   ├── ui-latest.png
│   ├── ui-<page-id>-latest.png
│   ├── source/                 # 独立源码仓库
│   ├── releases/<version>/     # 固件和匹配调试归档
│   └── logs/                   # 本地脱敏日志
├── 05-summaries/                # <日期>-<项目>-<版本>.md 和索引
└── 06-templates/                # 立项、总结、通用配置模板
```

只给一级分类加两位序号；不重排已有编号、不改 AGENTS/README 标准名、不编号 Git/BSP/源码内部目录。迁移时检查脚本、remote、链接和 CMake 缓存，历史交付路径保留为历史证据。

项目英文标识采用 2–5 个用途词、小写 kebab-case、3–48 字符，满足 `^[a-z][a-z0-9]*(?:-[a-z0-9]+)+$`；目录与 `feature/<project-name>` 一致，不含日期/版本/final/copy，不重复硬件前缀。中文显示名与英文标识分别记录；同用途先复用，Windows 大小写不敏感查重。必要 C 标识映射为下划线并登记。

派生固件独立 clone，记录上游 URL/提交/分支；不默认 worktree，不改变上游 main。权威项目文档在 source/docs/project，按上游约定中英成对；外层 README/总结仅结论和链接。公共素材记录来源/版本/许可，构建必需素材复制到应用 assets，不依赖另一台电脑的绝对路径。

## 模型选择与交接

先用 Sol 或 Astra 梳理需求/设计/任务/验收；普通需求优先 Sol。之后读工作区 `01-docs/model-selection.md`，六项 0–3 分分别记录证据：需求交互、BSP硬件、并发时序、数据通信、资源性能、验证定位。未知项先调查，不计零分。

| 级别 | 总分 | 选择起点 |
| --- | --- | --- |
| L0 | 0–2 | 明确局部改动：Luna Low/Medium |
| L1 | 3–5 | 简单离线应用：规格完整可 Luna Medium，端到端默认 Sol Medium |
| L2 | 6–9 | 普通常规应用：Sol Medium；恢复/状态复杂时 High |
| L3 | 10–13 | 多任务/网络/BSP：Sol High；困难架构可 Astra Medium/High |
| L4 | 14–18 | OTA/数据迁移/复杂竞态：Astra High 做设计诊断，明确实现可回 Sol |

新驱动、总线所有权、睡眠引脚或跨任务释放至少 L3；OTA/引导分区迁移保留数据、认证密钥机制按 L4 审查。环境缺失不是模型等级，电气事实不明不能靠高阶模型猜测。型号名称是创建时指南的约定，使用时核对实际可选模型；不固化价格或保证 token 节约，不修改全局模型设置或自动开多代理。

当前模型合适即可继续；需要切换时保存需求、设计决定、未决事项、路径/分支、验收和下一步，由用户通过可用入口切换，不假装已切换。依据返工、验证结果和实际用量再调整。

## 截图与总结

首次可运行 UI、每次可见改动和交付更新项目根目录 ui-latest.png 及相关页面图片。图片来自真实运行，不用设计稿冒充；模拟器和真机区分。设备截图尽量保留 240×320；Web 按实际手机/桌面视口，不套设备屏幕尺寸。

README 展示主截图并列其他图，记录北京时间、来源、页面状态、源码提交/dirty、构建身份和是否匹配；无固件写不适用。无法采集写缺失或过期，不为截图擅自烧录。发布快照归 releases/<version>/ui，旧交付不覆盖。总结登记真实测试、失败/未验项和下一步，不提交秘密或未经脱敏日志。
