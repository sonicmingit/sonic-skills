# AI Passport 通用 Web 配置页规范

版本：0.1；2026-11-07。适用于设备本地管理/配置页面，不代表云服务后台。无联网需求的离线应用不强制加入 Web 服务。

## 复用入口与状态

- 交互设计基线：passport-console（原工作区相对入口，见来源说明）。用户已选择电脑第一版、手机第二版。
- 可复制模板：06-templates/passport-console（原工作区相对入口，见来源说明），固定快照 `0.1.0-preview`；复制到目标应用后记录模板版本和改动，不反向覆盖公共模板。
- 当前模板为 React/Vite 前端演示，**没有真实扫描、连接或配对后端**。原型 视觉 QA（原工作区相对入口，见来源说明） 的 P2 密度差异仍待收敛；采纳其设计方向不等于取消这些待验项。
- 公共模板只承载通用配置。应用业务页面仍须独立设计，不能借复用配置页照搬上游测试 UI。

## 视觉与响应式

电脑使用品牌页头、网络/配对/设备导航和双栏网络页；手机使用单列“网络 → 配对 → 完成”向导，操作按钮便于触控。760px 是当前模板断点，可根据实测调整。保持官网近黑、白字、绿色强调、官方图标和 `AI PASSPORT//` 字标；素材本地打包并记录来源，不依赖外网字体、CDN 或官网在线加载。

Web 中文使用系统字体回退并检查目标浏览器实际显示；设备 LVGL 字库另行验证。检查 320/390px 手机、平板和桌面宽度、横竖屏、键盘焦点、错误关联、加载禁用与长网络名。最新运行截图放应用项目根目录，设计图单独标识。

## 通用行为

| 模块 | 必需行为 | 能力边界 |
| --- | --- | --- |
| 网络 | 设备异步扫描 2.4GHz、重扫、名称/信号/加密状态、隐藏网络、密码显隐、连接进度与失败重试 | 浏览器不能直接扫描设备周边 Wi-Fi；结果必须来自设备 |
| 热点 | `AI Passport-XXXXXX`，固定设备后缀；访问密码以设备现有配置或本机私有配置为准 | 后缀取工厂 MAC 末三字节的大写十六进制，换项目/重启保持不变；不是全球唯一保证 |
| 配对 | 按实际支持提供 Bridge 地址与端口、连接检测、确认绑定、重配/解绑 | 自动发现、配对码、二维码、BLE 配对只有协议已实现才显示，不虚构能力 |
| 设备 | 设备标识、应用/固件版本、网络和绑定状态；按能力提供识别/重启 | 清除网络、解绑、恢复配置分开且有确认；不新增不支持的操作 |
| 项目扩展 | 应用自己的配置区域、字段校验和恢复策略 | 不更改公共设备身份/品牌，不暴露密钥和内部实现细节 |

热点密码不等于路由器密码；也不能取代会话 token、API 密钥或协议加密密钥。存在旧 NVS 时只迁移对应本地访问密码配置，不能清空全部配置。完成经授权刷机后验证实际入口密码，而非只检查源码默认值。

## 接口与固件接入约束

接口路径按项目确定；建议能力划分为设备能力/身份、扫描启动/结果、连接请求/状态、配对检测/确认/解除。以下是契约要求，**不是已有 API 的声明**：

1. 开始耗时操作返回操作 ID，状态区分 idle/running/succeeded/failed；前端定时查询并有超时、取消或过期策略。收到保存请求不等于联网成功。
2. Wi-Fi 扫描和连接放工作任务，HTTP handler 不阻塞；评估 AP+STA 单无线电扫描期间的热点中断。连接后说明页面可能断开及重返方式，失败保留可恢复的配网入口。
3. 以实际 SSID 字节校验长度，处理同名 AP、隐藏 SSID、无效/不可显示字节及开放网络；不把网络名拼进 HTML。密码规则按加密类型核验，不能只沿用原型的简化 8–63 字符校验。
4. 检测与配对分开。校验地址、端口、协议版本及目标身份；网络/地址改变后旧结果失效。绑定持久化和失败回滚要有定义。配置请求沿用项目会话保护、敏感字段不回显且不记录到日志。
5. UI 通过设备自身接口通信；跨域、HTTPS 页面访问 HTTP Bridge 等限制应在设计时解决，不让浏览器绕过安全限制。按需求采用设备侧连接检测。
6. 离线资源进入固件构建产物，核对资源确实进入 0x0 合并镜像；记录未压缩/压缩大小、Flash 分区和峰值 RAM。浏览器运行 React 不等于 MCU 需要 Node，设备只提供静态资源与接口。
7. 演示数据和情境开关不得进入生产成功判定。真实接入前必须替换 mock 操作，检查刷新、断线、超时、重复提交、失败恢复与掉电持久化。

## 验收

前端构建和浏览器交互、接口主机测试、ESP-IDF 完整门禁、实机扫描/连接/配对分别记录。用真实设备验证固定后缀、访问密码、错误密码恢复、手机切网返回、中文显示和多设备辨识。未测项明确列出，不用模拟成功代替真机结果。固件完成后按交付规范提供已校验合并镜像，主动询问是否刷机；未经本次确认不烧录。
