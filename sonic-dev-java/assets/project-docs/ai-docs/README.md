# AI 生成的项目文档

这里集中保存 AI 辅助生成的项目记录。请将整个 `ai-docs/` 放在项目根目录。当前文件夹是模板，文件中的待填项和示例时间用于展示填写方式。

| 目录 | 存放内容 | 示例模板 |
| --- | --- | --- |
| `01-project-architecture/` | 现有目录、模块分层、功能到代码的索引，供快速查找 | [项目架构索引](01-project-architecture/20261117-143000_项目架构索引.md) |
| `02-requirements/` | 需求、范围、验收条件及待确认项 | [需求分析](02-requirements/20261117-143000_JAVA-001_需求分析.md) |
| `03-design/` | 开发方案、接口与数据变化、发布恢复和验证设计 | [开发设计](03-design/20261117-143000_JAVA-001_开发设计.md) |
| `04-development-logs/` | 实施、决策、验证结果及遗留事项 | [开发日志](04-development-logs/20261117-143000_JAVA-001_开发日志.md) |
| `05-agent-records/` | 项目分析后的接手记录与后续交接状态 | [Agent 接手记录](05-agent-records/20261117-143000_项目Agent记录.md) |

记录文档命名采用 `YYYYMMDD-HHmmss_任务编号_主题.md`，以北京时间（UTC+08:00）生成文件名。项目级文档可省略任务编号。文档内写明带时区的记录时间。固定入口 `README.md` 是唯一不带时间的文档。将模板用于真实项目时使用实际创建时间，并更新本页链接。

接手现有项目先建立架构索引，再写 Agent 接手记录。启动新任务时填写需求与设计，实施中追加日志。同一任务可复用同一份日志记录多个阶段，每条记录带时间。已有项目文档作为权威来源，在本目录通过链接引用。使用仓库相对路径，避免保存个人路径、凭据或未脱敏日志。

Git 项目默认将该目录加入本地忽略规则。在仓库根且目录名为 `ai-docs/` 时，添加 `/ai-docs/` 到 `git rev-parse --git-path info/exclude` 返回的文件。子项目按仓库相对路径设置规则，用 `git check-ignore -v -- ai-docs/README.md` 检查。若已被 Git 跟踪，先报告现状。只有明确指定允许提交的文档才进入 Git。非 Git 项目直接保存这些记录。
