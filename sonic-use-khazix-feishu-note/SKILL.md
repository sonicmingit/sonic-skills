# sonic-use-写作与飞书笔记

## 用途

当用户给你一个主题，希望你调用 `khazix-writer` 产出文章，并且把每次返回的文章新建成一篇飞书笔记，保存到指定知识库目录时使用。

## 目标

1. 先基于主题，按 `khazix-writer` 的方式生成文章
2. 每次输出都新建一个独立飞书笔记
3. 保存到用户指定的飞书知识库目录
4. 返回笔记链接或创建结果给用户

## 适用触发

- 给我一个主题，写成卡兹克风格文章，然后保存成飞书笔记
- 根据主题生成文章，并新建到飞书知识库
- 用 khazix-skills / khazix-writer 产出后，自动存入飞书知识库

## 标准执行流程

### 1. 接收主题

若用户只给了主题，优先直接开写。只有在主题过于空泛时，才追问最少必要信息。

### 2. 生成文章

调用 `khazix-writer` 的写作规范产出正文，遵守其文风、结构和禁区要求。

### 3. 创建飞书新笔记

把文章作为一篇新文档/笔记，写入指定飞书知识库目录。

默认目录：
- `https://my.feishu.cn/wiki/FCYbwuEqwiu6YdkJIgkctnzLn1c`

### 4. 命名规则

建议标题格式二选一：
- `YYYY-MM-DD 主题名`
- `主题名 - 卡兹克风格`

### 5. 输出结果

最终只返回以下信息：
- 笔记标题
- 飞书链接
- 创建是否成功

## 落地执行要点

- 每次都新建，禁止覆盖旧笔记
- 优先保存到用户指定知识库目录
- 若目录权限、创建接口或文档权限失败，立刻说明原因，并保留正文方便手动建档
- 不要泄露任何密钥、token、内部配置

## 失败兜底

如果飞书创建失败，返回：
- 文章正文
- 推荐标题
- 失败原因
- 让用户可手动创建的简短步骤

## 推荐调用方式

先用 `khazix-writer` 生成正文，再用飞书建文档能力创建新笔记。
