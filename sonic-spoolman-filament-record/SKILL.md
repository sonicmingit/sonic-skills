# Spoolman 耗材记录

## 概述

此 skill 用于快速记录新购买的 3D 打印耗材到 Spoolman 系统。

**自动化流程：**
```
用户输入 → 查询品牌 → 查询耗材 → (不存在则创建) → 创建线轴 → 完成
```

## 输入参数

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| --brand | ✅ | - | 品牌/供应商名称 |
| --name | ✅ | - | 耗材名称 |
| --material | ✅ | - | 材料类型：PLA/PETG/ABS/TPU/尼龙等 |
| --color | ❌ | - | 颜色名称或 HEX 值，如 "红色" 或 "#FF0000" |
| --price | ✅ | - | 购买价格（元） |
| --location | ✅ | - | 存放位置，如 "A1-货架" |
| --weight | ❌ | 1000 | 线轴初始重量（g） |
| --date | ❌ | 今天 | 购买日期，格式 YYYY-MM-DD |

## 工作流程详解

### Step 1: 供应商处理
1. 调用 `GET /api/v1/vendors?name=品牌名` 搜索供应商
2. 如存在，返回供应商 ID
3. 如不存在，调用 `POST /api/v1/vendors` 创建

### Step 2: 耗材查找
1. 调用 `GET /api/v1/filaments?name=耗材名&vendorId=供应商ID` 搜索
2. 如存在，返回耗材 ID，跳过 Step 3
3. 如不存在，进入 Step 3

### Step 3: 创建耗材（仅当不存在时）
1. 颜色名称转换为 HEX 值
2. 调用 `POST /api/v1/filaments` 创建耗材
3. 返回耗材 ID

### Step 4: 创建线轴
1. 调用 `POST /api/v1/spools` 创建线轴
2. 包含：购买日期、位置、价格、初始重量

## 自定义字段说明

创建线轴时会自动设置以下自定义字段：

| 字段名 | 来源 | 说明 |
|--------|------|------|
| buy_date | 购买日期 | 格式: YYYY-MM-DD |
| shop | 位置参数 | 购买店铺/渠道 |

> 注意：这些自定义字段需要在 Spoolman 系统中先创建定义才能生效。

## OCR 截图识别

如用户发送截图尝试获取信息，应先用 `image` 工具分析截图内容，提取关键信息后再调用此 skill。

**截图应包含的信息：**
- 品牌/供应商
- 耗材名称
- 材料类型（如 PLA）
- 颜色
- 价格
- 购买位置

## 颜色映射表

内置颜色映射位于 `data/colors.json`，包含 150+ 常用颜色名称。

**映射规则：**
1. 精确匹配（忽略大小写）
2. 模糊匹配（包含关系）
3. 视为 HEX 值（以 # 开头）
4. 都未匹配时使用原值

**部分内置颜色：**
- 红色 #FF0000 / red
- 蓝色 #0000FF / blue
- 绿色 #00FF00 / green
- 黄色 #FFFF00 / yellow
- 白色 #FFFFFF / white
- 黑色 #000000 / black
- 灰色 #808080 / gray
- 橙色 #FFA500 / orange
- 紫色 #800080 / purple
- 粉色 #FFC0CB / pink
- 棕色 #A52A2A / brown
- 金色 #FFD700 / gold
- 银色 #C0C0C0 / silver

## 错误处理

| 错误场景 | 处理方式 |
|----------|----------|
| API 连接失败 | 提示检查 Spoolman 服务状态 |
| 品牌创建失败 | 显示错误信息，终止流程 |
| 耗材创建失败 | 回滚（删除已创建的供应商），显示错误 |
| 线轴创建失败 | 保留耗材，仅提示线轴创建失败 |
