# 更新日志

## 2026-11-06

### 支持检查 GitHub 更新并安装到本机

- “查看技能有没有更新”等说法默认查询对应 GitHub 技能，将可确认的远端更新下载至 OneDrive，再更新当前 Agent 实际读取的技能目录。
- 明确上传与下载流程的调用方向、未指定技能时的已安装范围，以及目录链接和独立副本的处理方式。
- 补充本地修改保护、完整版本校验、安装结果验证和同步基线要求；纯下载保留原有日志，不生成回推提交。

## 2026-11-05

### 默认前缀统一为小写

- 新技能的英文目录、中文名称与显示名称默认统一使用小写 `sonic-` 前缀。
- 本规范目录改为 `sonic-skill-rules`，名称改为 `sonic-技能创建规范`，同步更新全局入口和安装链接。
- 扫描继续忽略前缀大小写，兼容已有技能；本次不批量重命名其他技能。

### 从 OneDrive 变量定位仓库并优先保存

- 检查更新时从 OneDrive、OneDriveConsumer、OneDriveCommercial 环境变量定位 `AI/skills/sonic`，支持不同机器的盘符与账户路径。
- 默认先将本机可确认的技能更新汇总保存到对应 OneDrive 目录，再与 GitHub 比较或推送；保留冲突副本并区分各阶段结果。
- 明确多个 OneDrive 仓库的选择、缺失环境变量时的回退，以及只读检测和不推送对比的行为。

### 支持自然语言检测自建技能

- 新增“检测我创建的 Skill”“检测我创建的技能”等调用说法，并保留原有调用方式。
- 维护源目录中的自建旧技能即使尚无 Sonic- 前缀也纳入检查；其他目录按前缀或明确归属识别，排除归属不明的第三方技能。
- 明确“只检测，不同步”只报告差异。

### 区分英文目录与中文技能名称

- 技能目录改用 Sonic- 前缀加英文，技能本身的名称、显示名称及说明仍使用中文。
- 本规范目录由 `Sonic-技能创建规范` 改为 `Sonic-skill-rules`，同步调整仓库入口、全局规则路径与安装链接。

### 新增本机检查与更新日志规则

- 新增按需扫描维护源、Codex、通用代理、Claude Code 用户目录及当前项目技能目录的流程。
- 新增 sonic- 前缀匹配、链接去重、完整内容比较、冲突判断和可确认本地更新的 GitHub 同步流程。
- 要求每个自建技能每次实际更新均维护中文 `CHANGELOG.md`，并与技能内容一起提交。
- 扩展技能说明和调用提示，支持“检查本机 sonic- 技能，有更新就同步”。

### 首次创建

- 配置用户级读取入口与指向维护源的技能链接。
