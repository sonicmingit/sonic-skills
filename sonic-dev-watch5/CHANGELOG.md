# 更新日志

## 2026-11-07 — 先设计、评估难度与选择子 Agent 模型

- 应用进入代码开发前先落盘详细需求与开发设计，按当前可用模型和任务风险选择最低合理成本的实施模型与推理档位，默认一个子 Agent 编码。
- 新增设计交接清单、难度参考、选型记录、精简上下文与主 Agent 验收方法；无法选模型时必须如实说明。
- 需要提高模型或推理成本时先给出失败证据、升级理由和范围并询问用户，避免盲目重试或重复委派；单纯文档、技能维护与 APK 复制不强制启动开发子 Agent。

## 2026-11-07 — 固定本机签名备份路径与换机恢复

- 所有手表 APK 开发与打包前确认并复用本机绝对备份路径，按包名保存密钥和恢复清单；换机只更换本机路径配置，继续使用原密钥。
- 每次签名前恢复或备份实际密钥并核对哈希、alias 和证书；备份失败、签名冲突或旧密钥缺失时停止，禁止构建脚本静默生成替代密钥。
- 明确密码独立保护、备份与日志分离，以及仅修改规范时不创建真实签名备份。
